# Clínica Vivere | Saúde Livre 🌿

Landing page editorial de alta conversão para a **Clínica Vivere / Saúde Livre** em Videira - SC.

## 🛠️ Tecnologias Utilizadas
- **Framework:** Next.js (App Router, Turbopack)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS v4 com paleta editorial azul médico / royal blue
- **Animações:** Framer Motion (efeitos de Aurora Background, Parallax interativo e scroll reveal)
- **Ícones:** Lucide React & ícones customizados
- **SEO & Structured Data:** Schema.org `MedicalClinic`, OpenGraph tags, otimização de imagens

## 🏥 Especialidades Integradas
- Medicina & Consultas Especializadas
- Vacinação & Imunização Humanizada (Saúde Livre)
- Psicologia Clínica & Apoio Emocional
- Fisioterapia & Reabilitação
- Psicopedagogia Clínica (Desenvolvimento Infantil)
- Nutrição Clínica & Funcional
